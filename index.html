01 Image Host — /images/

20 файлов hosted локально (скачаны, не внешние ссылки). Каждый — отдельный GET image/jpeg. Проверь Content-Type и Content-Length.

  • GET /images/tver1.jpg 45KB →
  • GET /images/wide.jpg 62KB 1200×400 →
  • GET /images/extra12.jpg 30KB →
curl -k -I https://localhost:4443/images/city.jpg
# Content-Type: image/jpeg | Content-Length: 46827

03 Video Host — /videos/

2 × MP4 hosted локально. Браузер шлёт Range: bytes=0-, сервер отвечает 206 или 200.

  • sample.mp4 947KB direct
  • sample2.mp4 947KB copy direct
curl -k -I https://localhost:4443/videos/sample.mp4
# Content-Type: video/mp4 | Content-Length: 969201

05 File Host — /data/ binaries

Бинарные типы: pdf, zip, bin, mp3 — тест octet-stream и download.
